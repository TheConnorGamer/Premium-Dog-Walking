# Premium Dog Walking — Paws & Paths

A warm, inviting single-page website for a premium dog walking and pet sitting service in London. Designed with organic shapes, playful animations, and a friendly terracotta-and-cream palette.

## Business Overview

Paws & Paths provides trusted, professional dog walking and pet sitting services. Every walker is DBS checked, insured, and canine first-aid trained. The service includes live GPS tracking and photo updates.

## Features

- Playful CSS-animated dog illustration in the hero
- Floating blob decorations with GSAP animations
- Walker profile cards with hover reveals
- GPS route map mockup with animated track
- Multi-step booking form with progress indicator
- Heart-themed testimonial cards
- Animated FAQ accordion
- Smooth Lenis scrolling
- Fully responsive with mobile navigation

## Technologies

React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion · GSAP · Lenis · React Icons

## Installation

```bash
npm install
npm run dev
```
